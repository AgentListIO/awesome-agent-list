# Contributing

Help keep [agentlist.io](https://www.agentlist.io) accurate and useful.

## Suggest an agent or a correction

[Open an issue in this repository](https://github.com/AgentListIO/awesome-agent-list/issues/new) with:

- The agent’s name and official website or repository.
- The proposed category or the field that needs correcting.
- A primary source supporting the addition or change.

This README is generated from the catalog that powers agentlist.io. Maintainers apply accepted changes to the catalog and regenerate the list; direct edits to generated entries may be overwritten.

## Ground rules

- Entries are editorial records, not endorsements or paid placements.
- Use official project links, without affiliate or tracking parameters.
- Include evidence for pricing, availability, and capability claims.
- Deprecated products are removed when the catalog retires them.
