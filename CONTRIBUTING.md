# Contributing

This list is generated from the catalog that powers [agentlist.io](https://agentlist.io) — the
source of truth is `data/catalog-seed.json` + `data/catalog-content.json` in
[arach/agentlist.io](https://github.com/arach/agentlist.io), and the README rebuilds via
`scripts/generate-awesome-list.py`.

## To add or update an agent

1. Open an issue or PR on [arach/agentlist.io](https://github.com/arach/agentlist.io) with the
   vendor name, homepage, and category — or propose the change directly against the seed files.
2. Once the catalog record lands, the README regenerates on the next pass.

Hand-edits to this README get overwritten — put corrections in the catalog, not the rendered list.

## Ground rules

- Entries are editorial records, not endorsements or paid placements.
- One line per entry, links to the vendor's own site plus the agentlist.io spec sheet.
- Deprecated products are removed on the refresh that retires them.
